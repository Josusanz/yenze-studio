# Online beta 0.3: create, recover and publish

Implemented:
- Automatic draft saving after a pause, with explicit failure state and retry. Typing during a slow save is preserved, and publication refuses an older snapshot.
- A scoped per-tab recovery copy. Recover only against the same server revision; conflicting copies remain downloadable and never silently replace newer work.
- Complete desktop/mobile customer preview with ordering disabled.
- Server-side publication checks for product/assets, print originals and checkout. Public links and embed instructions are available from the publication panel. Missing embed domains do not block sharing a standalone link.
- A furniture recipe with a working 3D table, selectable finishes, prices and an editable delivery question, alongside apparel and services.
- Scrollable creation dialogs, keyboard focus containment, Escape and focus return.
- Explicit recovery UI for a failed screen or failed 3D code download.
- Bounded decoded-artwork reuse, no empty print decals, and WebGL context release on disposal.
- PostgreSQL-aware preflight and scheduled public availability checks. The health route now actually queries the database.

Validation covers server rules/tenant boundaries, offline recovery, concurrent edits, guided creation, 2D/3D assets, keyboard operation, public sharing, quotes and print approval. The textile browser journey was split at the independently repeatable merchant workflow after the Linux trace showed the combined flow exhausted its total time budget. Assertions were retained; no retries were added.

Not activated or certified by this release:
- Provider-backed Stripe transactions and real email delivery: require credentials and a verified sender.
- A verified PostgreSQL backup restoration, operational ownership, independent security review and business pilots.
- Larger hosted files through direct object-storage uploads; the online beta currently limits files to 3 MB.
- Full English creator UI, native Wix/Framer/Squarespace carts, a universal CAD engine or guaranteed production/manufacturing equivalence.

Reference review (28 September 2026): [Zakeke's setup and test-order workflow](https://www.zakeke.com/) and [Threekit's configuration and guided-selling capabilities](https://www.threekit.com/product-configurator-software). The implementation prioritizes completing and validating a real product/order journey. These references are not evidence of feature parity or superiority.
