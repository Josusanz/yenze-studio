# Código abierto y servicio gestionado

Decisión para esta versión: el motor, el editor, los formatos, las plantillas incluidas, el backend y el SDK permanecen en la distribución AGPL-3.0-only. No se introduce un bloqueo de exportación, un contador ficticio de créditos ni una licencia premium que inutilice el autoalojamiento. Los assets de terceros mantienen sus licencias indicadas en NOTICE.

El servicio de pago propuesto es operativo: alojamiento, copias externas, almacenamiento, monitorización, instalación, adaptación de plantillas y soporte. No está abierto a contratación; no se anuncian SLA ni precios sin medir costes y validar el servicio. La web distingue «autoalojamiento disponible» de «servicio gestionado en preparación».

Los futuros packs de diseño deben especificar assets, licencia, soporte y compatibilidad de versión. No asumir que un pack puede cambiar las condiciones del motor ni introducir términos contradictorios con la licencia de esta distribución. Revisar cada aportación y sus derechos antes de publicarla.

Para abrir el proyecto: elegir repositorio público, subir únicamente la distribución saneada, activar CI y seguimiento de incidencias, nombrar responsables, publicar guía de contribución y políticas de versiones/migración. La publicación y los servicios externos requieren las cuentas del propietario; esta tarea local no los crea ni los simula.

Actualización: el repositorio de esta beta se publica en https://github.com/Josusanz/yenze-studio. El servicio gestionado sigue sin estar disponible para contratación.
