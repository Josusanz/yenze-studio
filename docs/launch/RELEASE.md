Yenze Studio is now available as an open-source, self-hosted beta.

Build product configurators from photos, layers, GLB models, primitive scenes or service choices without images. This release includes guided creation, nested choices, server-side pricing, saved configurations, quotes, order snapshots and customer proof approval. The apparel editor preserves original uploads and exports merchant PNGs at the configured physical resolution.

Start with Node 24 using the README. The current UI is Spanish. No customer data or credentials are included.

This is an early beta, not an audited hosted service. Provider-backed payments/email, production deployment and real business pilots need validation. WooCommerce is experimental and opt-in; other native carts and hosted subscriptions are not implemented.

Application code: AGPL-3.0-only. Included assets retain their documented licenses and attribution.
