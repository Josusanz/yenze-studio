# Creator usability review — 28 September 2026

Reviewed public official documentation, not private paid admin dashboards:

- [Kickflip: Build your first customizer](https://help.gokickflip.com/en/articles/5647561-build-your-first-customizer): begins with prepared imagery, then color controls and non-visual sizes; distinguishes input from display behavior; provides example files.
- [Zakeke: Create a customizable product](https://zakeke.zendesk.com/hc/en-us/articles/360026668693-Create-a-customizable-product): product source, product side/image, then printable area and customization settings.
- [Threekit: Product configurator software](https://www.threekit.com/product-configurator-software): emphasizes guided selling, real-time visuals/pricing and integrations. This is a product page, not evidence of merchant onboarding usability.

Yenze decisions:

1. Preserve the product-first workflow. Add an optional source helper that explains when photos, transparent layers or GLB are appropriate. For people without files, explicitly label included models as examples, not automatically generated replicas.
2. Create a root choice through concrete intentions: sizes, delivery, service mode, available 3D materials and optional existing parts. No file imports or geometry generation are implied by these choices.
3. Give editable starting answers with visible supplements and a customer-style choice preview. Changes apply atomically on confirmation; cancel does not change the product. Preview controls do not claim to render uncommitted geometry.
4. Block ambiguous names, invalid prices, unavailable targets and manifest size limits before insertion. Do not offer duplicate controllers for an already configured 3D target.
5. Explain the effect in plain language; put the technical effect selector behind advanced settings.
6. Add an explicit next step from choices to customer preview and then publication checks. Continuing to publication does not publish or send an order.

Validation: automated first-use journeys across image-free services and 3D products, mobile layout, duplicate-name correction, cancellation, undo/redo, source recommendations, and existing regression journeys. Real novice usability sessions and time-to-first-published-product measurements still require participants; no claim of being the easiest platform in the market is established by automated tests.
