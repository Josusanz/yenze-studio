Yenze Studio es un constructor de configuradores 2D, 3D y por opciones. El código de esta versión está disponible para autoalojarlo y contribuir bajo la licencia AGPL-3.0-only incluida en la descarga.

Lo que puedes aportar

  • Pruebas reales con productos de tu sector y pasos concretos para reproducir problemas.
  • Plantillas y modelos originales que puedas compartir legalmente.
  • Mejoras de accesibilidad, integraciones y traducciones.

Cómo empezar

Necesitas Node 24. Descomprime el paquete, ejecuta npm ci y npm run dev. Abre http://localhost:3060. Consulta README, CONTRIBUTING y SECURITY antes de desplegar.

Estado del proyecto

El repositorio público está en GitHub. Puedes comunicar problemas reproducibles y proponer mejoras mediante Issues. Esta página no anuncia un equipo de soporte, una comunidad ya existente ni certificaciones. La distribución incluye límites conocidos y pruebas reproducibles. El autoalojamiento y los servicios externos pueden tener costes.
